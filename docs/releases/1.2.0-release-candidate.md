## Known limitations and required disposition

- Maven is the supported blueprint output. Gradle guidance covers dependency declarations only.
- Kubernetes is supported for Streamable HTTP as a single-replica, process-local reference
  topology. Pod replacement does not preserve jobs, approvals, audit history, or results.
- Android/UiAutomator2 is supported; iOS/XCUITest generation is not.
- `latest` is optional and prohibited in reproducible consumers. If published, evidence must show
  that it equals the immutable `1.2.0` manifest digest.
- No resolved secret, credential, authorization value, receipt handle, raw sensitive payload, or
  proprietary artifact may appear in retained evidence.

## Rollback

Before promotion, delete or expire failed staging/evidence artifacts and rebuild from a corrected,
reviewed commit. After Maven publication, never overwrite released coordinates; publish a patch
release with migration or security guidance. For an image issue, remove the mutable alias from
promotion paths, retain the immutable digest and provenance for investigation, and publish a new
immutable patch tag. Revoke or mark compromised signatures/attestations according to the incident
process.
